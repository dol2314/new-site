# 전기차 보조금 원본 파일

원본을 그대로 보관하고, `node scripts/data/import-ev-subsidy.mjs`로 `packages/data/data/ev-subsidy/{연도}.json`을 만든다.
JSON을 손으로 고치지 말고, 원본을 바꾼 뒤 스크립트를 다시 돌린다.

| 파일 | 출처 | 기준일 | 이용 조건 | 받은 날 |
|---|---|---|---|---|
| `jeju-2026-09-17.cp949.csv` | 공공데이터포털 「제주특별자치도_전기자동차보조금지원대상현황_20260917」 https://www.data.go.kr/data/15048678/fileData.do | 2026-09-17 | 이용허락범위 제한 없음 | 2026-11-01 |

## 다른 지역 추가하기 (운영자)

무공해차 통합누리집은 자동 수집을 막는 보호 스크립트를 쓰므로 수집하지 않는다. 지자체 공고문(시·군·구 홈페이지)의 차종별 지방비 표를 보고
아래 형식의 UTF-8 CSV를 만들어 `region-{시도}-{시군구}-{공고일}.csv`로 넣는다.

```
차종,지방비보조금지원금액(만원),전환지원 지방비 지원금액(만원)
EV3 롱레인지 2WD 19인치,300,20
```

- 차종 이름은 제주 파일의 `차종` 칸과 글자까지 같아야 한다(스크립트가 맞지 않는 이름을 오류로 알려 준다).
- 공고문 URL과 공고일을 `regions.json`에 함께 적는다(스크립트가 출처로 쓴다).
