# 공개 계획 (2026-11-01 작성)

목표: 시기를 타는 페이지(전기차 취득세 감면 종료, 1월 연납)를 먼저 공개하고, 도구 5개 + 사례 글 20편을 갖춰 **2027년 1월 둘째 주** 애드센스를 신청한다(기획안 6장 일정 "1/10~1/20 신청"과 같음).

## 지금 상태

| 구분 | 공개 가능(검사 통과, 검수만 남음) | 보류(확인 전 데이터) |
|---|---|---|
| 도구 6개 | 자동차세·연납, 취등록세, 실구매가·할부(5년 비교 포함), 충전요금, 전기차 보조금 | 검사 기간·과태료 — `inspection/rules.json` 확인 전 5개 |
| 사례 글 5편 | 1편 전기차 취득세 12월 vs 1월, 2편 자동차세 연납, 4편 집 충전 vs 급속, 5편 전기차 vs 휘발유차 5년 | 3편 차 팔 때 자동차세 일할계산 — 이전일 당일 귀속 확인 전 |

보류 항목은 코드에 `hold`로 표시돼 있어, `published: true`로 바꾸면 빌드가 멈춘다(`lib/tools.ts`, `lib/guides.ts`).

## 막혀 있는 것 (운영자, 공개 전에 꼭)

1. **사이트 이름·도메인 확정과 연결** — 공개 뒤 URL·이름을 바꾸면 색인이 다시 시작된다(CLAUDE.md 규칙 7). `docs/runbook/launch-setup.md` 2장.
2. **운영자 정보** — Build variables `NEXT_PUBLIC_OPERATOR_NAME`(실명), `NEXT_PUBLIC_OPERATOR_EMAIL`. 소개·문의·개인정보처리방침에 나온다. 애드센스 심사에서 운영 주체가 보여야 한다.
3. **GA4 측정 ID** — `NEXT_PUBLIC_GA_ID`.
4. **검수** — 공개할 페이지마다 문장·숫자를 읽고 `reviewed: true`, `reviewedAt: "YYYY-MM-DD"`, `published: true`.

**검사 관련 글 3편**(늦으면 과태료, 검사 주기, 검사 비용)은 `inspection/rules.json` 확인 전 5개가 풀려야 쓸 수 있다.

## 묶음마다 하는 일

1. 검수한 페이지의 `reviewed`·`reviewedAt`·`published`를 바꾼다.
2. `npm run check:all` → 모두 통과.
3. 배포 후 서치콘솔 "URL 검사 → 색인 생성 요청", 서치어드바이저 "웹 페이지 수집 요청".
4. 다음 묶음 전에 서치콘솔 색인 상태 확인.
