## 이번에 고친 것 (점검 중 발견)

- **사례 글로 가는 길이 없었다.** 글 목록 페이지가 없고 홈·메뉴·도구 페이지 어디에도 글 링크가 없어, 글을 공개해도 사이트맵으로만 찾을 수 있었다. → `/guides/` 목록, 메뉴 "사례 분석", 홈 "사례 분석" 칸, 도구 페이지 "다음에 할 일"에 관련 글 링크를 추가했다.
- **"준비 중" 문구** — 전기차 보조금 계산기 지역 선택에 "그 밖의 지역 — 준비 중"이 나올 수 있었다 → 준비되지 않으면 항목 자체를 숨긴다.
- **보류 도구를 설명하는 문장** — 홈 소개 문장·사이트 설명에 공개하지 않는 "검사 기간과 과태료"가 들어 있었다 → 홈 문장은 공개된 도구 이름으로 만들고, 사이트 설명에서 뺐다.
- **면책 문구** — 할부·충전요금 도구에도 "관할 지자체가 정한다"는 세금용 문구가 붙어 있었다 → 도구별 문구로 바꿨다.
- **보류 장치** — 확인 전 데이터가 있는 도구·글에 `hold`를 달아, 공개로 바꾸면 빌드가 멈추게 했다.
