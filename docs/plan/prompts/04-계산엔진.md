# 프롬프트 04 — 계산 엔진 (packages/calc-core)

## 목표
웹과 앱이 함께 쓰는 순수 계산 함수. 모든 결과는 "숫자 + 계산 근거 설명"을 함께 돌려준다.

## Claude Code에게
```
docs/plan/README.md 3-2절, packages/data 의 스키마를 읽어라.

1. 함수 (입력 → { 결과, breakdown: [{label, value, rule, source_url}] }):
   - carTax({fuelType, displacementCc, firstRegisteredAt, year}) : 연 자동차세(지방교육세 포함), 차령 경감, 전기차 정액
   - carTaxPrepay({annualTax, payMonth, year}) : 연납 공제액·실제 절감률 (1·3·6·9월)
   - registrationTax({price, fuelType, isNew, isCompact, multiChild, year}) : 취득세, 감면, 한도
   - evSubsidy({modelId, sido, sigungu, extra: {youth, multiChild, lowIncome, firstCar...}, year}) : 국비 + 지방비 + 추가
   - energyCost({fuelType, kmPerMonth, efficiency, fuelPrice | chargingMix: {homePct, slowPct, fastPct}}) : 월 연료·충전비
   - inspectionSchedule({vehicleType, firstRegisteredAt, lastInspectionAt?}) : 다음 검사 기간, 지연 과태료 구간
   - tco({cars: [...3대], years, kmPerYear, residualRate?, insurancePerYear(입력), maintenancePerKm, loan?}) : 연도별 누적 총비용, 손익분기 주행거리
2. 데이터는 packages/data 에서 연도별로 로드. verified:false 값을 쓰면 결과에 warnings 로 표시.
3. 금액 반올림·절사 규칙은 법령·고지서 기준을 따르고, 규칙 출처를 주석으로.
4. 테스트(vitest 등): 함수마다 최소 6케이스 — 법령·위택스·공식 안내 예시, 경계값(배기량 1,000cc/1,600cc 경계, 차령 3년차, 연납 1월 vs 3월), 연도 전환.
   tco 는 손으로 검산 가능한 단순 케이스 2개 포함.
5. 문서: packages/calc-core/README.md 에 함수별 산식과 출처.
6. 테스트 결과와 verified:false 의존 함수 목록을 보고하라.
```
