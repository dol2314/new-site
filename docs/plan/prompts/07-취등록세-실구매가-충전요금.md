# 프롬프트 07 — 취등록세, 실구매가·할부, 전기차 충전요금

## 목표
구매 흐름을 잇는 도구 3개. 순서와 목표일: 취등록세(1/10) → 실구매가·할부(1/20) → 충전요금(2월).

## Claude Code에게
```
docs/plan/README.md 2-4·3-2·3-3절, docs/keywords/priority.md 2장(경쟁)·3장(하위 섹션)을 읽어라.
한 번에 하나씩, 각각 검사를 통과시킨 뒤 다음으로.

공통: 3-3절 8개 항목, 사례 3개는 엔진 계산값, "계산 방법"에 산식·출처·기준일, GA4 tool_start/tool_complete, 모바일 우선. published 플래그로 공개, verified:false 값을 쓰면 비공개.

1. /registration-tax/ 취등록세
   - 입력: 신차/중고차, 차량가(신차는 공급가액 기준 설명, 중고차는 실거래가·시가표준액 비교 설명), 연료, 경차·다자녀 등 감면 조건
   - 결과: 취득세, 감면액(한도·일몰일 표시), 합계. 공채 매입은 지역별로 달라 "별도, 지역 확인" 안내만(공식 값 없으면 계산하지 않는다)
   - 하위 섹션: 신차·중고차 과세표준, 경차·다자녀·전기차 감면, 이전등록 비용 구성, 중고 전기차 감면 조건
2. /car-loan/ 실구매가·월 납입금
   - 1단계 실구매가: 차값(직접 입력 또는 /ev-subsidy/ 프리셋), 보조금(전기차면 /ev-subsidy/ 엔진으로 자동 계산, 아니면 0), 취등록세(엔진), 탁송료 등 기타(직접 입력) → 실구매가
   - 2단계 할부: 선수금, 기간, 금리(사용자 입력 — 금리 기본값을 지어내지 마라. 공식 공시가 있을 때만 참고 범위 표시), 방식(원리금균등 / 원금균등 / 유예할부: 잔존가치율 입력) → 월 납입금, 총이자, 회차별 상환표(접기)
   - 3단계 5년 비용 비교(선택): 같은 조건에서 현금 vs 할부, 또는 차 2~3대(연료 다름) 비교 — 자동차세·연료/충전비(오피넷·충전요금 데이터)·보험(입력) 포함, 연도별 누적 그래프(표로도 제공)
   - 범용 할부 계산기와의 차이를 첫 3문장에 드러내라: "보조금·취등록세를 뺀 실제 할부 원금으로 계산".
   - 하위 섹션: 원리금균등 vs 원금균등, 유예할부의 마지막 회차, 선수금 효과, 중도상환수수료, 현금·할부·리스 비교
3. /ev-charging/ 전기차 충전요금
   - 요금표: 공공 급속·완속(2026-08 개편 내용 — 환경부·한전 공지로 확인), 주요 사업자 회원가(각 사업자 공식 공지 링크, 확인일), 주택용 요금(한전)
   - 계산기: 월 주행거리·전비·충전 비율(집/공용 완속/급속) → 월 충전비, 같은 거리 주유비(오피넷 오늘 유가, 연비 입력) 비교
   - 하위 섹션: 사업자별 회원가 비교, 집밥 요금, 급속만 쓸 때, 충전요금 할인 조건
   - 사업자 요금은 자주 바뀐다: 각 행에 확인일, 90일 지나면 validate-data 경고
4. 각 도구 공개 전 품질·SEO 검사와 테스트, 결과 보고.
```
