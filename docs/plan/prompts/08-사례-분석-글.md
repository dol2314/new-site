# 프롬프트 08 — 사례 분석 글 (주 3편, 매주 실행)

## 목표
도구마다 "특정 차 + 특정 조건 + 숫자" 사례 글을 붙여 롱테일 검색과 방문당 페이지뷰를 늘린다. 애드센스 신청 전 20편이 목표.

## Claude Code에게
```
docs/plan/README.md 3-4절, docs/keywords/priority.md 의 사례 글 후보를 읽어라.
이번 주 주제: {{운영자가 지정한 3개. 없으면 후보 중 아직 안 쓴 것 3개를 제안하고 승인받은 뒤 진행}}

글 형식 (/guides/{slug}/):
1. 제목: 차종 + 조건 + 숫자. 예) "연 2만 km 출퇴근, 아이오닉5 vs 투싼 하이브리드 5년 차이는?"
2. 첫 3문장: 결론 숫자, 기준일, 해당 도구 링크
3. 조건 표(차종·가격 기준일·주행거리·지역·충전 비율 — 가상 조건임을 명시)
4. 계산 단계: calc-core 를 실제로 실행한 값만. 단계마다 적용 기준 한 줄
5. 조건이 바뀌면? 변형 2개 이상(주행거리, 급속 비율, 지역)
6. 놓치기 쉬운 것 3가지 (운영자 메모 docs/field-notes/ 가 있으면 우선)
7. 관련 도구·글 링크 3개, FAQ 3개, 출처·기준일·검수일
8. 차종×지역 조합을 기계적으로 바꾼 글은 쓰지 않는다. 각 글은 고유한 질문 하나에 답한다.

검사(글마다, 결과 첨부):
- scripts/check-similarity.mjs (처음이면 만든다): 기존 글과 3-gram 겹침 30% 이상 문단 → 다시 쓴다
- 본문 숫자가 엔진 결과·데이터 값과 일치
- 1,500자 미만이거나 변형 2개 미만이면 공개 불가
- 차량 가격·제원은 제조사 공식 가격표·카탈로그 기준일 표시

draft(noindex, 사이트맵 제외)로 커밋하고 운영자 검수 체크리스트를 보고에 붙여라.
```

## 운영자 작업
