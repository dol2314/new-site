# 프롬프트 11 — 안드로이드 앱 "내 차 일정"(가칭) MVP

## 전제
- 04(calc-core), 10(calendar JSON) 완료
- 운영자: Google Play 개발자 계정, AdMob 앱 등록(앱 ID, 배너·네이티브 광고 단위 ID)

## Claude Code에게
```
docs/plan/README.md 4장을 읽어라. apps/mobile 에 만든다. packages/calc-core·packages/data 를 그대로 import 하고, 웹 빌드가 깨지지 않게 하라.

1. 스택: Vite + React + TypeScript + Capacitor(Android). 플러그인: @capacitor/local-notifications, @capacitor/preferences, @capacitor/app, @capacitor-community/admob. 현재 안정 버전 확인 후 고정.
2. 화면:
   a. 첫 실행: 내 차 등록(연료, 배기량, 최초등록일, 보험 만기일, 시도·시군구) — "휴대폰에만 저장" 명시, 건너뛰기 가능, 여러 대 등록 가능. 차량번호는 받지 않는다.
   b. 홈: 다가오는 일정 카드(검사 기간, 자동차세 납기, 연납, 보험 만기) + 이번 달 예상 연료비
   c. 일정: calendar JSON + 내 차 기준 자동 생성 일정, 항목별 알림 켜기/끄기
   d. 계산기: 총비용 비교, 자동차세·연납, 충전·주유비, 검사 기한 (calc-core)
   e. 기록(선택): 주유·충전 금액 입력 → 월별 합계 그래프
   f. 설정: 차 수정·삭제, 알림 전체 끄기, 개인정보처리방침, 라이선스, "정부 기관과 무관 + 정보 출처" 안내
3. 알림: 로컬 알림만. 검사 기간 시작 7일 전·시작일·마감 7일 전, 자동차세 납기 시작일·마감 3일 전, 연납 기간 시작일, 보험 만기 30일·7일 전, 오전 9시(Asia/Seoul). Android 13+ 알림 권한은 알림을 켤 때 요청. 정확한 알람 권한은 쓰지 않는다.
4. 데이터: 번들 포함 + 온라인이면 웹의 /data/calendar-2027.json·/data/fuel-latest.json 을 받아 schemaVersion 일치 시 교체.
5. AdMob: 홈·일정 하단 적응형 배너, 기록 목록 사이 네이티브(라벨 "광고"). 전면 광고 없음. 테스트 광고 ID로 개발, 실제 ID는 빌드 환경변수. UMP 동의 흐름.
6. 웹 환류: 상세 설명은 Custom Tabs 로 웹 페이지(utm_source=app).
7. 테스트: calc-core 테스트 재사용 + 일정 생성(검사 주기, 납기, 연도 경계, 윤년) + 알림 예약 시각.
8. 빌드: targetSdkVersion 은 Play 현재 요구(2026-08-31 이후 API 36 이상으로 알려짐 — Play Console 공지로 확인). 디버그 APK까지 빌드. 릴리스 키는 만들지 말고 docs/app/release-signing.md 에 절차.
9. docs/app/store-listing.md: 앱 이름 후보 3개, 짧은 설명(80자), 자세한 설명(정부 무관·출처 URL), 스크린샷 목록, 데이터 보안 답변 초안(기기 내 저장, AdMob 광고 ID).
10. 빌드·테스트 결과, 테스트 광고 스크린샷 보고.
```
