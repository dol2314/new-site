# 프롬프트 09 — 애드센스 승인 준비 + 광고 배치·정책 점검

## 목표
새 도메인 애드센스 승인을 한 번에 받고, 승인 후 정책 안에서 광고를 배치한다.

## 1단계: 승인 전 (도구 5개 + 글 20편 시점)
```
docs/plan/README.md 1장(2026 변경), 3-3절, 8장(리스크)을 읽어라.

승인 전 점검표를 실제로 확인하고 docs/adsense/pre-approval.md 로 보고하라:
1. 공개 페이지 목록: 도구 수, 글 수, 각 페이지 글자 수, 품질 검사 결과
2. 빈 페이지·"준비 중"·내용 없는 카테고리·깨진 링크(크롤러로 전체 링크 검사) 0개
3. about(운영자 실명·연락 수단), contact, privacy(애드센스 쿠키 고지), terms 존재
4. 내비게이션에서 모든 공개 페이지에 3클릭 이내 도달
5. 모바일 사용성: Playwright 모바일 뷰포트로 주요 페이지 스크린샷, 가로 스크롤·겹침 없음
6. ads.txt 형식, 사이트맵 제출 상태(운영자 확인 항목으로)
7. 서치콘솔 색인 페이지 수(운영자가 내보낸 파일이 docs/adsense/ 에 있으면 반영)
부족한 항목과 보강 작업 목록을 우선순위로 제안하라.
```

## 2단계: 승인 후
```
1. <AdSlot position=... /> 컴포넌트: 최소 높이 예약(CLS 방지), 화면 진입 시 로드, "광고" 라벨, 버튼·링크와 간격. 개발 환경에서는 회색 자리표시자만.
2. 기획안 3-7절 표대로 배치. 모바일 첫 화면(360×640)에 광고가 입력 폼보다 위에 오면 안 된다.
3. scripts/check-ad-policy.mjs: 광고 주변 200자 안 클릭 유도 문구, 페이지당 광고 수, 첫 화면 광고 여부(Playwright 스크린샷 + 요소 위치), history 조작 코드 검사.
4. 자동 광고는 "페이지 내 광고"만, 앵커·비네트는 2주 A/B 후 운영자 결정.
5. 결과: 페이지 유형별 광고 수, 스크린샷 경로, 위반 의심 목록.
```
