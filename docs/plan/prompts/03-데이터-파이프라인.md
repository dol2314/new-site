# 프롬프트 03 — 데이터 파이프라인

## 운영자 작업 (먼저)
- 오피넷 Open API 키 발급 → GitHub 저장소 시크릿 `OPINET_API_KEY`
- 공공데이터포털(data.go.kr) 회원가입 (필요한 API가 있으면 활용 신청)

## Claude Code에게
```
docs/plan/README.md 3-6절과 CLAUDE.md 규칙 1~3을 읽어라.

1. packages/data 구조:
   schema.ts (zod 등으로 모든 데이터 파일 검증)
   fuel/latest.json, fuel/history/YYYY-MM.json   # 유가
   electricity/charging.json, electricity/home.json  # 충전요금, 주택용 요금
   tax/car-tax-2026.json, tax/car-tax-2027.json     # 자동차세 세율, 차령 경감, 전기차 정액, 연납 공제율·기간
   tax/registration-2026.json, ...2027.json         # 취득세율, 감면(전기·하이브리드·경차·다자녀), 한도, 일몰일
   subsidy/national-2026.json, ...2027.json         # 국비(차종별), 추가 지원 조건
   subsidy/local-2026.json, ...2027.json            # 지자체별 지방비
   inspection/rules.json                            # 검사 주기, 과태료
   calendar/2027.json                               # 연납, 자동차세 납기, 보조금 공고(지역별) 일정
   모든 값은 CLAUDE.md 규칙 2의 필드를 가진다.

2. 오피넷: scripts/fetch-fuel.mjs — 공식 API로 전국·시도 평균(휘발유, 경유, LPG) 조회 → fuel/latest.json, 월별 history에 누적, 빌드 시 public/data/fuel-latest.json 으로도 공개(앱이 받아 감). GitHub Actions cron(매일 KST 오전 7시)으로 실행, 변경 있으면 커밋 → Cloudflare Pages 자동 배포. 키가 없으면 실패 메시지만 내고 끝낸다.

3. 세율·감면·검사 규칙: 법제처 국가법령정보센터의 현행 조문을 읽고 값과 조문 번호·URL을 기록하라. 2027년 시행 개정이 있는지(일몰 연장 포함) 확인하고, 미확정이면 verified:false.

4. 전기차 보조금:
   a. 무공해차 통합누리집(ev.or.kr)과 공공데이터포털에서 공식 API·다운로드 제공 여부를 먼저 찾아라.
   b. 없으면 ev.or.kr의 이용약관·robots.txt를 확인해 보고하고, 자동 수집 가능 여부를 운영자에게 묻는다. 답을 받기 전에는 수집 코드를 실행하지 마라.
   c. 허용되지 않으면: 운영자가 공고 시즌에 주 1회 표를 받아 CSV로 넣으면 변환하는 scripts/import-subsidy-csv.mjs 를 만든다(CSV 형식 문서 포함).
   d. 2026 값으로 먼저 채우고, 2027 지침이 나오면 같은 구조로 추가.

5. 충전요금·전기요금: 환경부 공용 급속·완속 요금, 주요 사업자 회원가, 한전 주택용 요금표를 공식 공지에서 확인해 입력.

6. scripts/validate-data.mjs: 스키마 검증, verified:false 목록 출력, checked_at 이 180일 지난 값 경고. CI에 추가.
7. /data/ 페이지가 이 데이터의 출처·기준일·갱신 기록을 자동으로 보여 주게 연결.
8. 보고: 데이터별 출처·수집 방식(API/수동)·verified 상태 표, 약관 확인 결과.
```
