# 프롬프트 05 — 대표 도구: 전기차 vs 하이브리드 vs 가솔린 총비용 비교 (/compare/)

## 목표
"이 조건이면 몇 년 타야 전기차가 이득인가"에 숫자로 답하는 페이지. 12/10 공개 목표.

## Claude Code에게
```
docs/plan/README.md 3-2·3-3·3-7절, docs/keywords/priority.md(있으면), packages/calc-core 의 tco 를 읽어라.

1. 입력 (간단 모드 기본, 자세히 모드 펼침):
   - 비교할 차 3대: 차종 프리셋(인기 차종 10~15개: 전기·하이브리드·가솔린 동급 세트, 가격은 제조사 공식 가격표 기준 + 기준일) 또는 직접 입력(가격, 연비/전비, 배기량)
   - 연 주행거리(슬라이더), 보유 기간(3/5/7/10년), 지역(시도·시군구 → 보조금·지방비), 충전 방식 비율(집 완속 / 공용 완속 / 급속)
   - 자세히: 보험료(직접 입력, 기본값은 비워 두고 "본인 견적 입력" 안내), 할부 금리·기간, 잔존가치율, 정비비
2. 결과:
   - 보유 기간 총비용 순위 카드 3개 + 차이 금액
   - 연도별 누적 비용 선 그래프(접근성: 표로도 제공), 손익분기 주행거리
   - "결과가 바뀌는 조건" 한 줄씩(예: 급속 충전 비율 60% 넘으면 하이브리드가 유리)
   - breakdown 펼치기: 항목별 금액과 근거
3. 페이지 구성: 3-3절 8개 항목 전부. 사례 3개는 실제 프리셋 조합을 엔진으로 계산(연 1만/1.5만/2.5만 km 등 조건이 서로 다르게). "계산 방법" 섹션에 모든 가정값·출처·기준일.
4. 공유: 결과 링크 복사(입력값은 URL에 넣지 않고 프리셋 ID·주행거리 구간만 — 개인 정보가 아님을 확인), 카카오톡 공유는 운영자가 앱 키를 주면 연결.
5. 광고: AdSlot 자리만(09에서 구현). 결과 바로 아래·계산 방법 앞·끝.
6. 성능: 계산은 클라이언트, 그래프 라이브러리는 가볍게(동적 import). 모바일 LCP 2.5초 이내 목표, Lighthouse 측정.
7. GA4: tool_start{tool:'compare'}, tool_complete{tool, winner_type, years_bucket, km_bucket}.
8. 품질 검사 스크립트 scripts/check-page-quality.mjs 를 만들어(8개 항목 존재 여부, 사례 숫자가 엔진 결과와 일치하는지) 이 페이지에 실행하라.
9. 빌드·테스트·Lighthouse·품질 검사 결과 보고.
```
