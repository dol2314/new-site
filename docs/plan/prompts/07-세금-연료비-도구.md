# 프롬프트 07 — 자동차세·연납, 취등록세, 충전·주유비, 검사 기한

## 목표
차 주인 전체가 쓰는 도구 4종. 자동차세·연납은 1월 16~31일 연납 시즌 전(12/20) 공개가 최우선.

## Claude Code에게
```
docs/plan/README.md 3-2·3-3절과 calc-core 함수를 읽어라. 한 번에 하나씩 만들고 각각 검사를 통과시킨 뒤 다음으로 넘어가라. 순서: car-tax → registration-tax → fuel-cost → inspection.

공통: 3-3절 8개 항목, 사례 3개는 엔진 계산값, "계산 방법"에 조문 번호·출처, 다음 할 일 링크(위택스·이택스 납부, TS 사이버검사소 예약 등 공식 경로), GA4 tool_start/tool_complete.

1. /car-tax/ 자동차세 + 연납
   - 입력: 연료(전기/하이브리드/가솔린/디젤/LPG), 배기량, 최초등록일(차령), 비영업용 승용 기준(다른 용도는 범위 밖임을 명시)
   - 결과: 연 세액(6월·12월 분할), 연납 시 1·3·6·9월별 절감액, 연납 신청 기간(해당 연도 공고 확인값), 신청 방법
   - 2027 연납 공제율이 미확정이면 2026 기준 + 배지
2. /registration-tax/ 취등록세
   - 신차/중고차, 차량가(공급가 기준 설명), 연료, 경차·다자녀 등 감면, 감면 한도·일몰
   - 공채 매입은 지역별로 다르므로 "별도, 지역 확인" 안내만(정확한 값 없으면 계산하지 마라)
3. /fuel-cost/ 충전·주유비
   - 오늘 유가(fuel/latest.json, 기준 시각 표시), 충전요금(집·공용 완속·급속)
   - 월 주행거리 → 연료별 월 비용 비교, 유가 30일 추이 작은 그래프
4. /inspection/ 검사 기한
   - 차종·용도·최초등록일(·직전 검사일) → 다음 검사 기간, 남은 날, 지연 시 과태료 구간(법령 확인값)
   - "앱으로 알림 받기" 자리(앱 출시 후 연결), .ics 다운로드(10에서 구현되면 연결)
5. 각 도구 공개 전 품질 검사·SEO 검사·테스트 실행, 결과 보고.
```
