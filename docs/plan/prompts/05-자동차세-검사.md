## Claude Code에게
```
docs/plan/README.md 3-2·3-3·3-7절, docs/keywords/priority.md 3장(하위 섹션)을 읽어라.
한 번에 하나씩 만들고 각각 검사를 통과시킨 뒤 다음으로 넘어가라. 순서: car-tax → inspection.

공통: 3-3절 8개 항목, 사례 3개는 엔진 계산값, "계산 방법"에 조문 번호·출처·기준일, 다음 할 일(공식 경로) 링크, GA4 tool_start/tool_complete, 모바일 우선(검색의 70~85%가 모바일). 공개는 site 레지스트리의 published 플래그로 하고, verified:false 값을 쓰면 공개하지 마라.

1. /car-tax/ 자동차세 + 연납
   - 입력: 연료(전기/하이브리드/가솔린/디젤/LPG), 배기량, 최초등록일(차령), 비영업용 승용 기준(다른 용도는 범위 밖임을 명시)
   - 결과: 연 세액(지방교육세 포함, 6월·12월 분할), 연납 시 1·3·6·9월별 절감액(실제 절감률 산식 공개), 해당 연도 연납 신청 기간, 위택스·이택스 신청 경로
   - 하위 섹션: 배기량별 세액표, 전기차·하이브리드 자동차세, 차령 경감표, 연세액 10만 원 미만 차량의 연납 가능 월, 중고차 매매 시 환급
   - 2027 연납 공제율이 미확정이면 2026 기준 + "2027 확정 전" 배지
   - 사례 3개: 2000cc 가솔린 차령 3년 1월 연납, 1598cc 하이브리드 3월 연납, 전기차
2. /inspection/ 검사 기간·과태료·비용
   - 입력: 차종·용도(비사업용 승용 등), 최초등록일, (선택) 직전 검사일 또는 등록증의 검사 유효기간 만료일
   - 결과: 다음 검사 기간(시작·끝), 오늘 기준 남은 날 또는 지난 날, 지연 시 날짜별 과태료 표와 상한 도달일, 정기 vs 종합검사 대상 여부와 수수료 범위
   - 하위 섹션: 차종·차령별 검사 주기, 검사 기간 계산 규칙, 과태료 기준(자동차관리법 시행령 별표 — 출처마다 상한 도달일이 다르게 퍼져 있으니 반드시 조문으로 확정), 검사 수수료, 재검사 기간, 공식 예약·조회 바로가기(TS 사이버검사소, 자동차민원 대국민포털)
   - 차량번호 조회 기능은 만들지 않는다(입력받지 않음). 조회는 공식 사이트 링크로.
   - 사례 3개: 만료 10일 전, 만료 40일 경과, 만료 200일 경과
   - "날짜 알림 받기": .ics 다운로드(프롬프트 10 이후 연결), 앱 출시 후 앱 링크 자리
3. 각 도구 공개 전 scripts/check-page-quality.mjs(없으면 만든다: 8개 항목 존재, 사례 숫자 = 엔진 결과), check-seo, 테스트 실행. 결과 보고.
4. 사이트맵·내비게이션·홈의 도구 카드는 published 레지스트리에서 자동으로 반영되는지 확인.
```
