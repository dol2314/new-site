# 프롬프트 01 — 키워드·경쟁 검증 + 이름 결정

## 목표
기획안 3-2절 도구 6개의 실제 검색량과 경쟁을 확인해 출시 순서를 확정하고, 사이트 이름·도메인을 정한다.

## 운영자 작업 (먼저)
1. 네이버 검색광고 → 도구 → 키워드 도구, 씨앗 키워드 입력 후 연관 키워드 **엑셀 내보내기** → `docs/keywords/naver-YYYYMMDD.xlsx`
   - 씨앗: 전기차 보조금, 전기차 보조금 지역별, 전기차 하이브리드 비교, 전기차 유지비, 하이브리드 유지비, 자동차세 계산, 자동차세 연납, 취등록세 계산기, 전기차 취득세, 전기차 충전요금, 유류비 계산, 자동차 검사 기간, 자동차 검사 과태료, 자동차 할부 계산기
2. 구글 키워드 플래너(가능하면, 입찰가 포함) → `docs/keywords/google-YYYYMMDD.csv`
3. 도메인 후보 3~5개의 등록 가능 여부 확인 → `docs/keywords/domains.md`에 메모

## Claude Code에게
```
docs/plan/README.md 2장·3장을 읽어라. 그다음 docs/keywords/ 의 파일을 모두 분석하라.

1. 키워드를 도구별(보조금 / 자동차세·연납 / 검사 / 취등록세 / 실구매가·할부 / 충전요금 / 총비용 비교 / 기타)로 묶어라.
2. 표: 키워드, 월 검색량(네이버 PC/모바일, 구글), 경쟁도, 구글 상단 입찰가(있으면), 검색 의도(계산 / 조회 / 비교 / 방법 / 기타), 월별 추이에서 피크 달.
3. 도구별 합계 검색량, 평균 입찰가, 피크 달을 요약하고 기획안 3-2절 출시 순서와 비교해 바꿀 점을 제안하라.
4. 같은 의도의 키워드는 한 페이지로 묶는다. 도구 페이지에 넣을 하위 섹션(예: "전기차 자동차세", "연납 3월 신청")과 사례 글 후보 20개를 뽑아라(차종·조건이 구체적인 것).
5. 웹 검색으로 도구별 상위 경쟁 페이지 5개씩을 찾아 "입력 항목 / 결과 / 계산 방법 공개 여부 / 기준일 표시 / 약점"을 표로 정리하라(페이지를 복사하지 말 것, 특징만).
6. docs/keywords/domains.md 가 있으면 이름 후보를 평가(짧음, 발음, 전기차에만 갇히지 않음)해 추천 1개.
7. 결과를 docs/keywords/priority.md 로 저장.

검색량 파일이 없으면 분석하지 말고 운영자 작업을 다시 안내하고 멈춰라. 수치를 추측해 채우지 마라.
```

## 완료 조건
- `docs/keywords/priority.md`: 도구별 검색량·입찰가·피크 달, 출시 순서 확정안, 사례 글 후보 20개, 경쟁 분석 표
