# 프롬프트 06 — 전기차 보조금 계산·지역 비교 (/ev-subsidy/)

## 목표
차종과 우리 동네를 고르면 국비+지방비+추가 지원 합계를 보여 주고, 시도별 차이를 한 표로 비교. 12/20에 2026 기준으로 공개, 2027 지침·공고가 나오면 데이터만 교체.

## Claude Code에게
```
docs/plan/README.md 2-4·3-2·3-3절, packages/data/subsidy, calc-core 의 evSubsidy 를 읽어라.

1. 입력: 차종(검색 가능한 목록, 제조사·모델·트림), 시도→시군구, 추가 조건 체크(청년 첫 차, 다자녀, 차상위 이하, 기존 내연기관차 폐차·판매 등 — 해당 연도 지침에 있는 것만).
2. 결과: 국비 / 지방비 / 추가 지원 / 합계, 지급 조건 요약, 신청 절차(대리점 통해 신청 등), 공고·잔여 현황 확인 공식 링크.
   잔여 대수는 03에서 자동 수집이 허용된 경우에만 "N월 N일 기준"으로 표시. 아니면 공식 링크만.
3. 지역 비교 표: 선택한 차종으로 17개 시도(대표 시군구 또는 시도 평균 — 데이터 구조에 맞게)의 합계를 한 표에. 지역별 개별 페이지는 만들지 마라(대량 생성 금지).
4. 연도 처리: 2027 데이터가 verified 되기 전에는 2026 기준 + "2027 지침 발표 예정" 배지. 데이터가 들어오면 기본 연도가 자동 전환.
5. 3-3절 8개 항목. 사례 3개: 같은 차를 다른 지역에서 샀을 때, 추가 지원이 붙을 때 등 — 엔진 계산값.
6. 실구매가·할부(/car-loan/)와 연결: 보조금 결과에서 "이 보조금으로 실구매가·월 납입금 계산" 버튼(차종·지역 프리셋 전달). /car-loan/ 이 공개되기 전에는 버튼을 숨긴다.
7. GA4: tool_complete{tool:'ev-subsidy', sido, has_extra}.
8. 품질 검사·빌드·테스트 결과와 verified:false 목록 보고.
```
