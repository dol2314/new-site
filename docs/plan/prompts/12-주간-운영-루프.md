# 프롬프트 12 — 주간 운영 루프 (매주 월요일)

## 운영자 작업 (10분)
`docs/weekly/YYYY-MM-DD/`에 내보내기 파일 저장:
- 서치콘솔: 실적(페이지·검색어, 최근 28일·직전 28일), 페이지 색인 보고서, 생성형 AI 실적 보고서
- 네이버 서치어드바이저: 유입 키워드·수집 현황
- 애드센스: 페이지별 RPM·노출·클릭(최근 28일)
- GA4: tool_complete(도구별), calendar_add, pwa_install, 페이지별 세션
- (앱 출시 후) Play Console 설치·유지, AdMob 수익

## Claude Code에게
```
docs/weekly/ 의 이번 주와 지난주 폴더를 비교하라.

1. 요약: 일 평균 방문, 방문당 PV, 페이지 RPM, 월 예상 수익, 색인 페이지(구글/네이버), 상위 검색어 10개 — 지난주 대비
2. 기획안 6장 수익 추정표와 비교. 2주 연속 보수 시나리오 아래면 경고하고 원인 후보 제시.
3. 기회:
   a. 노출 상위 20%인데 클릭률 낮은 페이지 → 제목·설명 개선안 2개씩
   b. 순위 8~20위 검색어 → 보강할 섹션
   c. RPM 상위 5개 페이지의 공통점 → 다음 사례 글 후보
   d. tool_start 대비 tool_complete 낮은 도구 → 입력 단계 개선안
4. 위험: 색인 제외 급증, RPM 급락, 크롤링 오류, 데이터 checked_at 180일 경과(validate-data 결과), 다가오는 시즌 대비 미갱신 데이터(예: 12월인데 2027 연납 공제율 미확인)
5. 이번 주 할 일 3개(어느 프롬프트로, 예상 시간). 운영 시간 주 10~15시간.
6. docs/weekly/YYYY-MM-DD/report.md 로 저장. 파일에 없는 수치는 "데이터 없음".
```
